How the Interest score is built

Every brand's Interest is a single number, rescaled so the average of the top-5 brands = 100. It is built in two layers:

Interest  =  %%ATT_PCT%%% Attention  +  %%BREADTH_PCT%%% Breadth   →   rescaled so the top-5 average = 100, then tiered A / B / C

Attention · %%ATT_PCT%%% of the score — four signals

The four signals below, each √-scaled against the top-5 brands then blended by the weights shown. If a brand is missing a signal, the weights renormalise over the ones it has (a source with no value is dropped, never counted as zero).

Breadth · %%BREADTH_PCT%%% of the score

A steadying factor: how many Wikipedia language editions the brand has an article in — a rough "is this a globally-known brand" check, so one viral month in a single market can't top the chart.

Wikipedia pageviews use the median monthly views across all languages — robust to one-off spikes (a designer's death, a viral collab) that a 12-month total would bank as lasting attention. No figure is estimated; missing is missing.

Sources: Google Trends, Wikipedia pageviews, GDELT news, Reddit, Wikidata. Free public data only; not investment advice.
